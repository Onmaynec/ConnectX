# ConnectX v0.3.0-alpha.5 — Unified Guarded Prerelease

Alpha.5 сохраняет repeated TLS strategy evidence из alpha.4 и заменяет набор одноразовых publisher workflows единым guarded release pipeline.

## Что изменилось

- добавлен строгий `release/prerelease.json`;
- publisher запускается только после successful Android CI push-run в `main`;
- CI artifacts и release commit используют один exact SHA;
- PR, failed CI, wrong branch и SHA mismatch отклоняются;
- manifest, application version, native version, README и changelog проверяются автоматически;
- добавлены negative tests для подмены event, branch, SHA, tag, paths и stale README;
- release bundle содержит `PROVENANCE.json` и SHA-256;
- повторный запуск не заменяет отличающиеся assets;
- старые version-specific publisher workflows удалены из активной конфигурации;
- application version: `0.3.0-alpha.5`, versionCode `12`;
- native bridge: `connectx-go-bridge/0.3.0-alpha.5`.

## Проверки

- release guard unit/negative tests;
- Go dependency lock и bridge tests;
- JVM tests и Android lint;
- сборка debug APK для arm64-v8a и x86_64;
- native/legal APK payload verification;
- Android 35 x86_64 strategy, evidence, JNI, TCP, UDP и DNS gates;
- exact successful main CI provenance;
- deterministic asset packaging и checksum generation.

## Ограничения

- маршрут остаётся только `192.0.2.0/24`;
- default IPv4/IPv6 route отсутствует;
- обычный пользовательский трафик не обрабатывается;
- нет HTTP request, авторизации, private API, MITM или расшифровки HTTPS;
- два write-вызова не считаются доказательством двух TCP-сегментов;
- положительный evidence относится только к выбранной цели и текущей сети.
