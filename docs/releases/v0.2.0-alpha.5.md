# ConnectX v0.2.0-alpha.5 — Bounded UDP Path Probe

Alpha.5 добавляет первый проверенный UDP-путь через Android TUN и source-built native stack. Обычный интернет-трафик по-прежнему не перехватывается.

## Что добавлено

- отдельная кнопка `Проверить UDP-путь через TUN`;
- типизированный режим `native_udp_probe`;
- bounded UDP echo endpoint только на IPv4 loopback `127.0.0.1`;
- SOCKS5 `UDP ASSOCIATE` после обязательной per-run аутентификации;
- exact-only target override `192.0.2.1:18081`;
- outbound UDP socket проходит `VpnService.protect()` до отправки;
- случайный 64-байтовый nonce и проверка точного echo-ответа;
- latency, upload/download bytes, association и datagram counters;
- generation-safe teardown probe socket, native stack, TUN, relay и echo endpoint;
- JVM end-to-end тест SOCKS5 UDP relay;
- Android emulator gate для реальных TCP и UDP путей через foreground `VpnService`.

## Проверяемый путь

```text
Android IPv4 DatagramSocket
  → маршрут 192.0.2.0/24
  → Android TUN
  → fd-backed Go/gVisor stack
  → tun2socks SOCKS5 UDP ASSOCIATE
  → authenticated relay на 127.0.0.1
  → exact override 192.0.2.1:18081
  → protected loopback UDP echo endpoint
  → тот же путь обратно
```

Probe считается успешным только если:

1. echoed nonce полностью совпал;
2. native bridge получил UDP flow;
3. relay подтвердил authenticated UDP association;
4. relay подтвердил хотя бы один обмен datagrams;
5. upload/download counters не меньше размера nonce;
6. после результата native bridge остановлен и ресурсы закрыты.

## Исправления Android UDP lifecycle

- probe socket теперь явно привязывается к IPv4 wildcard `0.0.0.0`, а не к потенциальному IPv6 dual-stack wildcard;
- после создания VPN route выполняется короткий bounded settle;
- разрешено не более трёх попыток, каждая использует новый socket и ту же единственную TEST-NET цель;
- SOCKS5 UDP fragmentation (`FRAG != 0`) отвергается;
- native transport counters позволяют различить отсутствие UDP flow и ошибку relay, не записывая адреса, payload или credentials.

## Как проверить на устройстве

1. Установите APK поверх alpha.4.
2. Откройте ConnectX.
3. Нажмите `Проверить UDP-путь через TUN`.
4. Подтвердите системное VPN-разрешение Android.
5. Дождитесь автоматического завершения probe.
6. Проверьте latency, upload/download bytes, associations и datagrams.
7. Повторите probe несколько раз и отдельно проверьте остановку кнопкой `Выключить`.

## Ограничения безопасности

- TUN route остаётся только `192.0.2.0/24`;
- `0.0.0.0/0` и `::/0` не добавляются;
- UDP ASSOCIATE доступен только в явном диагностическом режиме;
- разрешена только точная цель `192.0.2.1:18081`;
- relay и echo endpoint не слушают LAN-интерфейсы;
- DNS, IPv6, QUIC и DPI-стратегии не включены;
- удалённые серверы ConnectX не используются;
- HTTPS не расшифровывается и сертификаты не устанавливаются;
- содержимое трафика и SOCKS credentials не выводятся;
- версия не заявляет рабочий обход блокировок.
