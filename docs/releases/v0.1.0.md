# ConnectX v0.1.0 Foundation Preview

Первая техническая preview-сборка ConnectX.

## Что реализовано

- Android 10 и новее;
- интерфейс на Jetpack Compose и Material 3;
- системный запрос разрешения на локальный `VpnService`;
- foreground service и постоянное уведомление;
- безопасное создание, повторный запуск и закрытие локального TUN;
- остановка из приложения и системного уведомления;
- обработка отзыва системного разрешения;
- unit-тесты, Android lint и сборка APK через GitHub Actions.

## Важное ограничение

Это **Foundation Preview**, а не рабочая версия обхода блокировок.

В этой версии отсутствуют:

- userspace TCP/UDP packet engine;
- полноценный перехват интернет-трафика;
- DPI-обфускация;
- автоматический подбор стратегии;
- root-режим.

Для безопасной проверки lifecycle TUN маршрутизирует только зарезервированную тестовую сеть `192.0.2.0/24`. Обычный интернет-трафик устройства не перенаправляется через ConnectX.

ConnectX не использует удалённый VPN-сервер, не выполняет MITM, не устанавливает сертификаты и не расшифровывает HTTPS.

## Проверки

Перед публикацией workflow выполняет:

- unit tests;
- Android lint;
- `assembleDebug`;
- расчёт SHA-256 APK.

## Установка

Скачайте APK из Assets. Android может попросить разрешить установку приложений из браузера или файлового менеджера.

Эта preview-сборка подписана стандартным debug-ключом CI и предназначена только для раннего тестирования.
