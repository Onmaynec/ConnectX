# ConnectX v0.2.0-alpha.3 — Controlled Native Self-Test

Третья alpha-сборка сетевого движка ConnectX.

## Что добавлено

- отдельная кнопка `Native self-test` в существующем интерфейсе;
- отображение ABI, native-версии и результата диагностики;
- явный режим сервиса `native_self_test`;
- запуск authenticated TCP relay;
- создание Android TUN только с маршрутом TEST-NET-1 `192.0.2.0/24`;
- передача дубликата TUN fd в source-built tun2socks/gVisor bridge;
- проверка `isRunning()` после JNI start;
- остановка native session до закрытия TUN и relay;
- mode-aware status broadcasts и unit-тесты переходов состояния;
- x86_64 Android-emulator smoke-test реальной native-библиотеки;
- проверка JNI version, locked upstream SHA, контролируемой invalid-fd ошибки и идемпотентного stop.

## Что означает self-test

Self-test подтверждает, что Android может:

1. загрузить `libconnectxbridge.so`;
2. вызвать JNI API;
3. создать безопасный TEST-NET TUN;
4. передать дубликат fd в userspace stack;
5. запустить и остановить native lifecycle без завершения приложения.

Это ещё не означает, что обход блокировок работает.

## Важные ограничения

- маршрут `0.0.0.0/0` не добавляется;
- маршрут `::/0` не добавляется;
- обычный интернет-трафик телефона не проходит через ConnectX;
- UDP и DNS passthrough пока отсутствуют;
- IPv6 и QUIC/HTTP3 пока отсутствуют;
- DPI-обфускация пока отсутствует;
- удалённые серверы ConnectX не используются;
- HTTPS не расшифровывается;
- пользовательские сертификаты не устанавливаются.

## Как проверить на устройстве

1. Установите APK поверх предыдущей alpha.
2. Откройте ConnectX.
3. Убедитесь, что в карточке показаны ABI и native version.
4. Нажмите `Запустить native self-test`.
5. Подтвердите системное разрешение Android.
6. Убедитесь, что статус изменился на `Native self-test активен`.
7. Нажмите `Выключить` и проверьте возврат в состояние `Выключено`.
8. Повторите запуск/остановку несколько раз.

Обычный интернет при этом не должен пропадать, потому что self-test перехватывает только зарезервированную тестовую сеть.
