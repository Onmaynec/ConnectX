# ConnectX v0.2.0-alpha.2 — Native Bridge Preview

Вторая alpha-сборка сетевого движка ConnectX.

## Что добавлено

- source-built Android native bridge на Go;
- userspace TCP/IP stack на базе tun2socks/gVisor;
- JNI API `version/start/stop/status/error`;
- безопасная передача дубликата Android TUN fd во владение native-кода;
- закрытие переданного fd на каждом success/error пути;
- идемпотентная остановка;
- сборки `arm64-v8a` и `x86_64`;
- проверка наличия обеих native-библиотек внутри APK;
- host-тесты валидации и владения fd;
- фиксированные версии tun2socks, Go и Android NDK;
- third-party notices и MIT license tun2socks.

## Важное ограничение

Native bridge включён в APK, но по умолчанию выключен feature flag. Обычный трафик Android пока не передаётся в gVisor stack.

ConnectX по-прежнему создаёт только безопасный тестовый маршрут `192.0.2.0/24`. Маршрут `0.0.0.0/0` не будет включён до проверки на физическом устройстве:

1. загрузка `.so` на arm64;
2. JNI self-check;
3. передача дубликата TUN fd;
4. повторные start/stop;
5. отзыв разрешения Android;
6. отсутствие утечки fd;
7. восстановление сети после ошибки.

## Пока не поддерживается

- рабочий обход блокировок;
- default-route passthrough;
- UDP и DNS passthrough;
- IPv6;
- QUIC/HTTP3;
- DPI-обфускация.

## Приватность

- удалённые серверы ConnectX не используются;
- HTTPS не расшифровывается;
- пользовательские сертификаты не устанавливаются;
- локальный relay требует случайную аутентификацию;
- содержимое трафика не журналируется.
