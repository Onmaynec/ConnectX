# План реализации ConnectX

## Принцип

Каждый этап заканчивается только после проверки сборки и тестов. Нельзя считать стратегию рабочей лишь потому, что её код написан.

## Фаза A — исследование

- Сравнить userspace TCP/IP stacks и tun2socks-подобные архитектуры.
- Проверить лицензии исходных проектов и библиотек.
- Определить минимальный packet path для TCP, UDP, IPv4 и IPv6.
- Составить threat model.
- Проверить актуальные ограничения Android и Google Play.

**Выход:** архитектурное решение и таблица зависимостей без неподтверждённых обещаний.

## Фаза B — Android-каркас

- Kotlin, Gradle Kotlin DSL, version catalog.
- Compose Material 3.
- Минимальные модули `app`, `core:model`, `core:common`, `vpn:api`, `vpn:service`, `vpn:engine`.
- Экран состояния с mock-данными.
- Unit-тесты состояний.

**Выход:** собираемый APK без сетевого обхода.

## Фаза C — локальный TUN passthrough

- Разрешение `VpnService`.
- Foreground service и уведомление.
- TUN для IPv4, затем IPv6.
- Прямые защищённые исходящие сокеты.
- TCP и UDP passthrough.
- Без удалённого сервера.
- Корректный stop/reconnect/network change.

**Выход:** приложения продолжают подключаться к реальным серверам через локальный движок.

## Фаза D — первая стратегия

Первая стратегия выбирается только после прототипа packet path. Приоритет — минимальная и измеримая техника, например контролируемое дробление ранних данных TLS-потока в userspace TCP proxy, если тесты подтвердят, что сервер получает неизменный поток.

- Стратегия оформляется отдельным модулем.
- Есть включение/выключение.
- Есть контрольные тесты без стратегии и со стратегией.
- Есть безопасный fallback.
- Нет чтения прикладного содержимого сверх минимально необходимой классификации рукопожатия.

**Выход:** одна стратегия, проверенная на реальных устройствах и сетях.

## Фаза E — расширение

- UDP/QUIC.
- Автоматический подбор.
- Диагностика YouTube, Telegram и Discord.
- Исключения приложений.
- DNS-настройки.
- Root-режим как отдельная экспериментальная ветка.

## Критерии первого MVP

- Android 10+.
- Нет серверов ConnectX.
- Нет MITM и сертификатов.
- Стабильный запуск и остановка.
- Прямой TCP/UDP passthrough.
- IPv4 обязателен; статус IPv6 явно указан.
- Одна подтверждённая стратегия.
- Аварийное отключение возвращает обычную сеть.
- Логи не содержат payload, URL-параметры, cookies или токены.
- Debug APK собирается в CI.
- Есть реальные результаты тестов на физическом устройстве.
