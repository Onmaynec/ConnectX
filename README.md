# ConnectX

ConnectX — Android-приложение для локальной обработки и обфускации сетевого трафика с целью повышения устойчивости соединений к DPI-фильтрации.

## Важное отличие от VPN

ConnectX не является сервисом удалённого VPN и не перенаправляет пользовательский трафик через сервер разработчика.

На Android без root системный `VpnService` рассматривается только как разрешённый ОС механизм создания локального TUN-интерфейса и получения IP-пакетов приложений. После локальной обработки пакеты должны отправляться напрямую реальным серверам назначения.

ConnectX не выполняет MITM, не расшифровывает HTTPS, не устанавливает пользовательские сертификаты и не читает содержимое переписки.

## Текущий статус

Проект находится на этапе 0: проверка технической осуществимости локального DPI-bypass на Android.

На этом этапе не утверждается, что обход уже реализован или подтверждён на реальных сетях.

## Ближайшая цель

Создать минимальный Android-прототип, который:

1. получает трафик через локальный TUN без удалённого VPN-сервера;
2. безопасно пропускает IPv4/IPv6, TCP и UDP напрямую к назначению;
3. предоставляет модульную точку для локальных стратегий обфускации;
4. не анализирует содержимое HTTPS;
5. измеряет стабильность, задержку и ошибки;
6. корректно запускается и останавливается без потери сети.

## План

- Этап 0 — feasibility, архитектура и лицензии.
- Этап 1 — каркас Android-проекта.
- Этап 2 — локальный TUN passthrough-прототип.
- Этап 3 — первая проверяемая стратегия обфускации.
- Этап 4 — UI, диагностика и автоматический выбор стратегии.

Подробности находятся в каталоге `docs/`.
