# ConnectX v0.3.0-alpha.7 — Physical Device Evidence Kit

Alpha.7 добавляет воспроизводимый путь проверки ConnectX на физическом Android arm64-устройстве и измерение file-descriptor lifecycle для repeated TLS evidence.

## Добавлено

- privacy-safe device class, Android API и ABI family;
- FD before/after/delta после полного teardown;
- typed bounded FD assessment;
- redacted evidence report schema v3;
- три последовательные TEST-NET evidence-сессии в instrumentation;
- strict physical arm64 collector;
- allow-list bundle validator и negative privacy tests;
- physical-device runbook.

## Проверка релиза

- release guard и repository consistency;
- JVM unit tests, включая environment/FD policy и bundle validator;
- Android lint;
- APK, обе ABI и legal payload;
- Android 35 strategy, repeated evidence, JNI, TCP, UDP и DNS gates;
- exact successful main commit publication.

## Ограничения

- CI использует x86_64 emulator и не заменяет physical arm64 execution;
- collector readiness не является restricted-network proof;
- #11 требует отдельный schema v3 report из реальной ограниченной сети;
- #22 закрывается только после приложенного physical arm64 lifecycle bundle;
- обычный трафик приложений не проходит через ConnectX.
